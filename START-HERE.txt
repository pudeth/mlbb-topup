          Double-click → start.bat
          
          (Directly starts all services)


  ┌────────────────────────────────────────────────────────────┐
  │  🚀 STEP 2: FIRST TIME SETUP                               │
  └────────────────────────────────────────────────────────────┘

      If this is your FIRST TIME running:
      
          1. Double-click → install.bat
             (Wait 3-5 minutes for installation)
          
          2. Double-click → start.bat
             (3 windows will open)
          
          3. Open browser → http://localhost:3001


  ┌────────────────────────────────────────────────────────────┐
  │  ⚡ STEP 3: DAILY USAGE                                    │
  └────────────────────────────────────────────────────────────┘

      Start working:    Double-click → start.bat
      
      Stop working:     Double-click → stop.bat
      
      Restart:          Double-click → restart.bat
      
      Check status:     Double-click → status.bat


  ┌────────────────────────────────────────────────────────────┐
  │  🌐 STEP 4: OPEN APPLICATION                               │
  └────────────────────────────────────────────────────────────┘

      After starting services:
      
          Browser → http://localhost:3001
          
          ✓ No login required
          ✓ Click "Top Up Now"
          ✓ Enter Player ID
          ✓ Select package
          ✓ Pay with KHQR

  ┌────────────────────────────────────────────────────────────┐
  │  🆘 TROUBLESHOOTING                                        │
  └────────────────────────────────────────────────────────────┘

      Something not working?
      
      1. Double-click → stop.bat
      2. Wait 5 seconds
      3. Double-click → start.bat
      
      Still not working?
      
      1. Open → menu.bat
      2. Select option [4] Check Status
      3. See which services are running
