## ☁️ Option 2: Deploy to Free Cloud (Vercel + Render)

### Step 1: Push your Code to GitHub
Create a private or public GitHub repository for this project and push the code:
```bash
git add .
git commit -m "Add Docker and deployment configs"
git push origin main
```

### Step 2: Deploy Frontend on Vercel (100% Free)
1. Go to [Vercel](https://vercel.com/) and log in with GitHub.
2. Click **"Add New Project"** and select your GitHub repository.
3. Set **Root Directory** to `frontend`.
4. Add Environment Variable:
   - `REACT_APP_API_URL`: `https://your-backend-service.onrender.com/api`
5. Click **Deploy**. Your frontend is now live with a free `https://*.vercel.app` domain and free SSL!

### Step 3: Deploy Backend & KHQR on Render (100% Free)
1. Go to [Render.com](https://render.com/) and log in with GitHub.
2. **Deploy KHQR API**:
   - Click **New +** -> **Web Service**.
   - Select your repository.
   - Root Directory: `Scorekhqr-bakong`
   - Runtime: `Docker` (Render will automatically detect `Scorekhqr-bakong/Dockerfile`).
   - Copy the URL generated by Render (e.g., `https://mlbb-khqr.onrender.com`).
3. **Deploy Backend API**:
   - Click **New +** -> **Web Service**.
   - Root Directory: `backend`
   - Runtime: `Docker` (Render will automatically detect `backend/Dockerfile`).
   - Add Environment Variable:
     - `KHQR__ApiUrl`: `https://mlbb-khqr.onrender.com`
   - Click **Deploy**.

## 🐳 Option 3: Single Free VPS (Oracle Cloud Free Tier / Docker)

If you get a free Linux VM (Oracle Cloud Free Tier):
1. Install Docker:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```
2. Clone your repository:
   ```bash
   git clone <your-repo-url>
   cd <your-repo>
   ```
3. Launch all 3 services with one command:
   ```bash
   docker compose up -d --build
   ```
4. Everything (Frontend on port 3001, Backend on 5000, KHQR on 5001) will run automatically.
