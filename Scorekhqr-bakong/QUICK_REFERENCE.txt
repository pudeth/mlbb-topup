================================================================================
    API ENDPOINTS
================================================================================

POST /api/payment/create
  - Create new payment
  - Returns: bill_number, md5_hash, qr_code, qr_image_url

GET /api/payment/qr/<md5>
  - Get QR code image
  - Returns: PNG image

GET /api/payment/status/<md5>
  - Check payment status
  - Returns: PAID or UNPAID

GET /api/payments
  - List all payments
  - Query: ?status=UNPAID&limit=20
