================================================================================
    TROUBLESHOOTING
================================================================================

Problem: Still showing UNPAID but I paid
Solutions:
1. Check if MD5 hash matches
2. Verify token in .env is valid
3. Check API server console for errors
4. Manually test API:
   http://localhost:5000/api/payment/status/[MD5]

Problem: Token errors
Solution:
1. Get new token from Bakong Developer Portal
2. Update BAKONG_TOKEN in .env
3. Restart servers: start_all.bat

Problem: Rate limit errors (429, 503)
Solution:
- This is normal, system handles it automatically
- Just wait, it will retry
- Don't manually check too often

Problem: Want to test without API
Solution:
1. Edit .env: DEMO_MODE=true
2. Restart servers
3. Status will always show UNPAID (for testing UI)
